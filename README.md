# 科学の甲子園 情報の傾向と対策

図解スライドの総合編（37枚）と年度別解説（87枚）。2022〜2025年度の全国大会・情報分野の過去問をもとに、目的・条件・考え方を学ぶ教材です。

## 公開ページ

https://itou-daiki.github.io/science-koshien-informatics/

- トップページから総合編・テーマ別・年度別の教材を開けます。
- [総合編](https://itou-daiki.github.io/science-koshien-informatics/overview.html)
- 問題図、スタックと再帰の段階図、学習計画を掲載しています。
- 「AICodeで試す」から、コードを入力した状態の実行環境へ移動します。
- 下部のボタン・選択欄、または左右キーでスライドを移動できます。
- AICodeとWebフォントの利用にはインターネット接続が必要です。

## 年度別解説

[年度別の一覧](https://itou-daiki.github.io/science-koshien-informatics/years/)

| 年度 | 枚数 | 主な内容 |
| --- | --- | --- |
| [2022](https://itou-daiki.github.io/science-koshien-informatics/years/2022.html) | 22 | 再帰・帰納法・累乗・フィボナッチ数 |
| [2023](https://itou-daiki.github.io/science-koshien-informatics/years/2023.html) | 20 | コピー操作・筆算・循環小数 |
| [2024](https://itou-daiki.github.io/science-koshien-informatics/years/2024.html) | 20 | スタック・一般化・環状線・到達判定 |
| [2025](https://itou-daiki.github.io/science-koshien-informatics/years/2025.html) | 25 | 累積人数・安定な並べ替え・仕事の割り当て・近似の保証 |

第11問・第12問の設問に沿って、問題の条件、前提知識、思考の流れ、コツ、学習方法を解説します。コード12例はAICodeへ入力済みの状態で開けます。難しい証明には「発展」の表記があります。

## 出典と範囲
