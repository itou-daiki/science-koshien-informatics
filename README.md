# 科学の甲子園 情報の傾向と対策

高校1年生向けの図解スライド（37枚）。2022〜2025年度の全国大会・情報分野の過去問をもとに、目的・条件・考え方を学ぶ教材です。

## 公開ページ

https://itou-daiki.github.io/science-koshien-informatics/

- 問題図、スタックと再帰の段階図、学習計画を掲載しています。
- 「AICodeで試す」から、コードを入力した状態の実行環境へ移動します。
- 下部のボタン・選択欄、または左右キーでスライドを移動できます。
- AICodeとWebフォントの利用にはインターネット接続が必要です。

## 出典と範囲

[JST 科学の甲子園 公式過去問](https://koushien.jst.go.jp/koushien/pastexam/index.html)

問題図とコードは原題をもとにした学習用の簡略例であり、原題の全文・全設問の再掲ではありません。全国大会4年分の整理であり、予選や次回の出題を予測するものではありません。
