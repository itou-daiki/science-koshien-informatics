# 科学の甲子園 情報の傾向と対策

図解スライドの総合編（47枚）と年度別解説（103枚）。2022〜2025年度の全国大会・情報分野の過去問をもとに、目的・条件・考え方を学ぶ教材です。

## 公開ページ

https://itou-daiki.github.io/science-koshien-informatics/

- トップページから総合編・テーマ別・年度別の教材を開けます。
- [総合編](https://itou-daiki.github.io/science-koshien-informatics/overview.html)
- 問題図、スタックと再帰の段階図、学習計画を掲載しています。
- 「AICodeで試す」から、コードを入力した状態の実行環境へ移動します。
- 下部のボタン・選択欄、または左右キーでスライドを移動できます。
- AICodeとWebフォントの利用にはインターネット接続が必要です。

[用語と考え方の基礎](https://itou-daiki.github.io/science-koshien-informatics/basics.html)

変数・条件分岐・配列・スタックとDUP・関数・再帰・余り・最小性に、累乗・コピーを加えた10項目。図、確認問題、答えの理由、過去問へのリンクを掲載。全スライド下部からも開けます。

## 更新

`index.html`（トップ）、`assets/`、`overview.html`（総合編）、`years/` 内のHTMLを更新して `main` ブランチへ反映すると、GitHub Pagesに公開されます。

各問題の直前に、必要な用語・図で追う例・着眼点を説明する準備ページを追加。問題ページからも直前の準備へ戻れます。既存の `#slide-N` は元の内容を指し、準備ページは `#prep-N` です。

スタック・再帰の準備ページと基礎ページでは「次の1手」「戻る」「最初から」で状態を追えます。再帰の動作例は2枚・1枚で停止する説明用の手順です。年度別の原題コード（0枚で停止）とは区別しています。

並べ替えは読む人・得点別の置き場所・結果を同時に表示。仕事の割り当ては追加前の合計、最小値の選択、追加後の変化を分けて操作できます。ともに基礎ページ・総合編・2025年度に掲載しています。

循環小数（1÷6）は余りの記録・10倍・商と余り・循環判定を操作できます。環状線は6駅の練習例で1区間ずつ移動し、両方向の区間数と所要時間を比較します。基礎ページ・総合編・対応する年度別の準備ページに掲載。

累乗は2⁸を順に掛ける7回と、結果を2乗して再利用する3回を比較。コピーは別フォルダ・同一フォルダの候補作成、衝突確認、採用、追加を1手ずつ追えます。
